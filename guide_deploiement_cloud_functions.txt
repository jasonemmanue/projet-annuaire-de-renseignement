----------------------------------------------------------------
ÉTAPE 2 — CONTENU DE index.js
----------------------------------------------------------------

Le fichier utilise la syntaxe firebase-functions v2 (obligatoire).
Les imports corrects sont :

  const { onDocumentCreated } = require("firebase-functions/v2/firestore");
  const { onSchedule }        = require("firebase-functions/v2/scheduler");
  const { setGlobalOptions }  = require("firebase-functions/v2");
  const admin                 = require("firebase-admin");

  admin.initializeApp();
  setGlobalOptions({ region: "europe-west1" }); // fixe la région pour toutes les fonctions

ERREUR FRÉQUENTE : utiliser l'ancienne syntaxe v1 :
  ❌  functions.firestore.document(...).onCreate(...)   ← NE FONCTIONNE PLUS
  ✅  onDocumentCreated("...", async (event) => {...})  ← CORRECT v2

Signature du handler v2 :
  - event.data.data()   → données du document créé
  - event.params.convId → paramètres du chemin

----------------------------------------------------------------
FONCTIONS DÉPLOYÉES
----------------------------------------------------------------

1. sendChatNotification
   - Région   : europe-west1
   - Trigger  : Firestore onCreate sur conversations/{convId}/messages/{msgId}
   - Rôle     : envoie une notification push FCM au destinataire
                dès qu'un nouveau message est créé
   - Visiteurs anonymes : pas de notification (pas de token FCM)

2. cleanupOldMessages
   - Région   : europe-west1
   - Trigger  : planifiée toutes les 168 heures (1 fois par semaine)
   - Rôle     : supprime les messages Firestore de plus de 90 jours
                pour limiter les coûts de stockage


----------------------------------------------------------------
ERREURS CONNUES ET SOLUTIONS
----------------------------------------------------------------

ERREUR : functions.firestore.document is not a function
→ Cause   : syntaxe firebase-functions v1 utilisée avec le SDK v2
→ Solution: utiliser onDocumentCreated() (voir Étape 2)

ERREUR : Project or database '(default)' does not exist
→ Cause   : base Firestore non créée
→ Solution: créer la base (voir Étape 3)

ERREUR : Permission denied while using the Eventarc Service Agent
→ Cause   : rôles IAM manquants, APIs pas encore propagées
→ Solution: configurer les permissions (voir Étape 6)
            puis attendre 2-3 minutes et relancer

ERREUR : Build failed — missing permission on build service account
→ Cause   : compte Cloud Build sans les droits nécessaires
→ Solution: ajouter les rôles au compte Cloud Build (voir Étape 6)

QUESTION : "How many days to keep container images?"
→ Répondre : 1  (suffisant, évite les frais de stockage)

Vérifie qu'il a bien ces rôles (ajoute ceux qui manquent) :

Cloud Build Service Account
Cloud Functions Developer
Artifact Registry Writer
dans mon cas

COMMANDES UTILES
----------------------------------------------------------------

Déployer uniquement les fonctions :
  firebase deploy --only functions

Déployer uniquement les règles Firestore :
  firebase deploy --only firestore:rules

Déployer uniquement les règles Storage :
  firebase deploy --only storage

Tout déployer :
  firebase deploy

Voir les logs des fonctions en temps réel :
  firebase functions:log

Lister les fonctions déployées :
  firebase functions:list
